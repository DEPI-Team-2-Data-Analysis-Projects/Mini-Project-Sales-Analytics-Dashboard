# Mini-Project-Sales-Analytics-Dashboard
Mini-Project | Sales Analytics Dashboard – Power BI

في الـ Mini-Project ده اشتغلنا كفريق على تصميم وتطوير Dashboard تفاعلي باستخدام Power BI بهدف تحليل بيانات المبيعات وتقديم رؤية واضحة عن أداء المبيعات والأرباح والمنتجات والعملاء، بما يساعد على اكتشاف الأنماط والاتجاهات واستخراج Insights تدعم اتخاذ قرارات أفضل.

1. Data Preparation & Cleaning

بدأنا بتجهيز البيانات وتنظيفها باستخدام Power Query، وعملنا على:

- مراجعة البيانات وفهم طبيعة الأعمدة وأنواعها.
- معالجة القيم الناقصة والتأكد من جودة البيانات.
- مراجعة أنواع البيانات وتصحيحها عند الحاجة.
- إزالة التكرارات والأخطاء التي قد تؤثر على نتائج التحليل.
- تجهيز البيانات لتكون مناسبة للتحليل وبناء الـ Data Model.

2. Data Modeling

بعد تجهيز البيانات، بنينا Data Model منظم باستخدام Star Schema، وعملنا على:

- تنظيم البيانات في Fact Table وDimension Tables.
- إنشاء العلاقات المناسبة بين الجداول.
- مراجعة اتجاهات العلاقات والتأكد من سلامة الـ Data Model.
- تحسين تنظيم البيانات لتسهيل كتابة المعادلات وإنشاء التقارير.

3. DAX Measures & KPIs

استخدمنا DAX لإنشاء Measures تساعدنا على قياس الأداء وتحليل النتائج، ومن أهمها:

- Total Sales: إجمالي المبيعات.
- Total Profit: إجمالي الأرباح.
- Total Orders: إجمالي الطلبات.
- Total Quantity: إجمالي الكميات المباعة.
- Profit Margin: هامش الربح.
- Average Order Value: متوسط قيمة الطلب.
- Discount: تحليل الخصومات.
- Returned Orders: تحليل الطلبات المرتجعة.

4. Dashboard Design & Business Analysis

صممنا Dashboard تفاعليًا يضم عدة صفحات، بحيث تركز كل صفحة على جانب مختلف من جوانب الأداء:

- Overall Performance Analysis: متابعة مؤشرات الأداء الرئيسية وتقييم الأداء العام للمبيعات والأرباح والطلبات.
- Product & Category Analysis: تحليل أداء المنتجات والفئات ومقارنة المبيعات والأرباح لتحديد المنتجات الأفضل أداءً.
- Customers Analysis: فهم أنماط الشراء وتحليل مساهمة العملاء في المبيعات.
- Geographic Performance Analysis: مقارنة الأداء بين المناطق الجغرافية وتحديد المناطق الأعلى في المبيعات والأرباح.
- Shipping Performance Analysis: تحليل بيانات الشحن والطلبات لفهم أداء الشحن ومقارنة النتائج وفقًا للبيانات المتاحة.

5. Interactivity & User Experience

اهتمينا بجعل الـ Dashboard سهلة الاستخدام والاستكشاف من خلال:

- استخدام Slicers لتصفية البيانات حسب الاختيارات المتاحة.
- إضافة Filters للوصول إلى تفاصيل محددة.
- استخدام Interactive Visuals لاستكشاف العلاقات بين المؤشرات المختلفة.
- تنظيم الصفحات وتسهيل الانتقال بينها باستخدام Interactive Navigation.
- اختيار الرسوم البيانية المناسبة لطبيعة كل تحليل، مع الاهتمام بوضوح التصميم وسهولة قراءة النتائج.

Tools & Technologies

Power BI | Power Query | DAX | Data Modeling | Star Schema | KPIs | Data Visualization | Slicers | Filters | Interactive Navigation

Project Outcome

من خلال المشروع، طبقنا مراحل تحليل البيانات بدايةً من تجهيز البيانات وتنظيفها، مرورًا ببناء الـ Data Model وإنشاء الـ DAX Measures، وصولًا إلى تصميم Dashboard تفاعلي يساعد على فهم أداء المبيعات واكتشاف الأنماط ومقارنة النتائج بطريقة منظمة.

كان هدفنا إننا نتجاوز مجرد عرض الأرقام في Charts، ونحوّل البيانات إلى معلومات واضحة وInsights تساعد على تقييم الأداء ودعم اتخاذ قرارات مبنية على البيانات.
